# Wyckoff — phase phân phối (distribution)

> **Vault tag:** skill  
> **Brand fit:** Alpha ⭐⭐  
> **Source:** Richard D. Wyckoff (modern summaries); synthesized

## Concept

**Distribution** mirror accumulation — sau uptrend, smart money **bán dần** cho public FOMO. Các nhãn tương tự: PSY (preliminary supply), BC (buying climax), AR down, ST up, **SOW** (sign of weakness — break range down).

Đặc điểm: range sau markup dài, volume trên up move yếu dần, **upthrust** (false break up) trước markdown. Retail vẫn long “breakout” trong khi smart exit.

Trading: fade strength ở premium, hoặc chờ SOW + retest range bottom. Không short sớm giữa range — chờ evidence phân phối hoàn tất.

## XAUUSD context (ví dụ áp dụng)

Vàng tăng 3 tuần, H4 range $2,400–$2,450, upthrust $2,452 close back trong box — cảnh báo distribution. Short setup sau break $2,400 với retest (không khuyến nghị cụ thể — chỉ framework).

## Key takeaway

Distribution = **bán cho đám đông mua đỉnh** — chờ upthrust + break down confirm.
