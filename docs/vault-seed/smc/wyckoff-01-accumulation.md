# Wyckoff — phase tích lũy (accumulation)

> **Vault tag:** skill  
> **Brand fit:** Alpha ⭐⭐  
> **Source:** Richard D. Wyckoff (modern summaries); Hank Pruden interpretation — synthesized

## Concept

**Accumulation** là giai đoạn smart money **mua dần** trong range sau downtrend — chuẩn bị markup. Các phase thường dạy (paraphrase): **PS** (preliminary support — bắt đầu hấp thụ), **SC** (selling climax — panic sell), **AR** (automatic rally), **ST** (secondary test — test lại đáy), **SOS** (sign of strength — break range với demand).

Price trong range sideways, volume pattern thay đổi — spring (false break down) thường xuất hiện trước markup. Trader không cần label đủ 5 phase — quan trọng nhận **range + absorption + break up**.

Map sang intraday: accumulation có thể là vài giờ đến vài ngày trên H4/D1 vàng.

## XAUUSD context (ví dụ áp dụng)

Sau dump CPI, XAUUSD sideway H4 1 tuần, spring dưới range low rồi reclaim — trader Alpha coi là accumulation nhỏ, chờ SOS break range high để bias long swing.

## Key takeaway

Accumulation = **smart money mua trong range** — tìm spring + break up, không đuổi đỉnh đầu rally.
